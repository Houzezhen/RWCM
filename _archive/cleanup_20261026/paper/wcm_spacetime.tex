\title{From WCM to SpaceTime: Fixed-Query Visual History Encoding for Robot Value Prediction}
\author{WCM Project}
\date{October 2026}

\begin{document}
\maketitle

\begin{abstract}
Visual histories can resolve state ambiguity in robot value prediction, yet their length increases the input sequence seen by the critic. We develop \SpaceTime{}, an extension of the World Critic Model (WCM) that encodes eight sampled frames from two cameras through a shared vision backbone and temporal interaction layers, then reduces the history to 64 learned queries. Holding the number of frames, queries, model blocks, and training schedule fixed, we compare histories spanning 60 and 120 frame offsets. Across three seeds on a 125-episode out-of-distribution (OOD) set, the 60-offset system reduces paired value-prediction error relative to the original WCM. Extending the span to 120 offsets further lowers paired OOD mean squared error for all three seeds, with episode-bootstrap 95\% intervals excluding zero. An episode-level success/failure diagnostic on an 18-episode checkpoint-validation split additionally shows 18/18 correct predictions at frame 2 for each \SpaceTime{} seed. These results support fixed-query encoding of a longer sampled history in the evaluated robot task; they do not imply fixed inference cost or a new temporal-attention operation.
\end{abstract}

\section{Introduction}

The value of a robot state depends on progress that may be ambiguous in a single image. A short sequence can expose motion and interaction context, but carrying more frames through a critic also increases the visual input. The original \WCM{} uses local history for action-free value prediction, whereas its visual interface does not explicitly compress a longer sampled history into a fixed-size set of tokens. This study asks whether a fixed latent interface can make a longer visual history useful for value prediction.

\SpaceTime{} processes eight observations at selected historical offsets. A shared ViT encodes each camera frame, temporal layers mix information across observed times, and Perceiver-style cross-attention reduces the resulting sequence to 64 learned queries \citep{dosovitskiy2021vit,jaegle2021perceiver}. The downstream WCM consumes this fixed-size representation. We test the route from the original WCM to an eight-frame history at maximum offset 60, then change only the sampling offsets to cover a maximum offset of 120. The main experiment therefore isolates temporal span within the \SpaceTime{} system rather than proposing a new attention primitive.

The evidence follows three steps. First, we compare original WCM and \SpaceTime{} on paired OOD endpoints. Second, we compare the two \SpaceTime{} spans under the same model and evaluation protocol. Third, we inspect the model's trained failure-risk output on an episode-disjoint validation split and place it beside a value-based diagnostic from the original WCM. The latter uses different prediction heads and is interpreted as a system-level comparison.

\section{Method}

\subsection{Original WCM and prediction targets}

The original \WCM{} predicts an action-free state value $\hat V_t=f_V(\mathcal{H}_t,p_t)$ from its short local history $\mathcal{H}_t$ and proprioceptive state $p_t$. Action is consumed by the separate $Q(s,a)$ and action-conditioned dynamics paths after the value path. The \SpaceTime{} systems retain value, $Q$, and dynamics heads and also train a failure-risk head. Its logit $r_t$ uses the target $y_t^{\mathrm{fail}}=1-y_t^{\mathrm{success}}$, so $\sigma(r_t)$ is a failure score. The original WCM checkpoint has no risk head; its failure diagnostic below is constructed from $-\hat V_t$.

\subsection{Fixed-query history encoder}

For a maximum sampled offset $k$, let
\begin{equation}
\mathcal{X}^{(k)}_t=\left(x_{t-\delta_1},\ldots,x_{t-\delta_8}\right),
\qquad \max_i\delta_i=k.
\end{equation}
We denote this eight-frame history by $H_k$. The two offset lists are
\begin{align}
H_{60}:  &[0,9,17,26,34,43,51,60],\\
H_{120}: &[0,17,34,51,69,86,103,120].
\end{align}
Offsets are frame indices, not elapsed seconds or numbers of input frames. An offset preceding the episode start is clamped to the first frame, so the earliest predictions repeat that frame in several historical slots.

Each of the two camera views is passed through a shared ViT $\phi$. With 224-pixel inputs, each view yields one CLS token and 196 patch tokens. Eight frames from two cameras therefore produce $8\times2\times197=3152$ visual tokens before reduction. The \SpaceTime{} representation is
\begin{equation}
h_t^{(k)}=\Pi_{64}\!\left(\Psi_\theta\bigl(\phi(\mathcal{X}^{(k)}_t)\bigr)\right),
\qquad \hat V_t^{(k)}=g_V(h_t^{(k)},p_t),
\end{equation}
where $\Psi_\theta$ contains two factorized temporal layers and $\Pi_{64}$ contains two Perceiver-style reduction layers. The 64 output queries each have width 384. The vision backbone is trainable and the CLIP text features are frozen \citep{radford2021clip}. Figure~\ref{fig:system} shows the input and fixed-query interface. Here ``fixed'' describes the 64-query latent bottleneck: input pixels, FLOPs, and wall-clock time are reported separately.

\section{Experimental protocol}

\subsection{Models and value evaluation}

The experimental route is original WCM $\rightarrow$ T8--$H_{60}$ \SpaceTime{} $\rightarrow$ T8--$H_{120}$ \SpaceTime{}. The two \SpaceTime{} variants have the same architecture, 64-query bottleneck, same-seed Image-B4 initialization, and two-stage schedule: ten joint epochs followed by three full fine-tuning epochs. Their only changed model input is the offset list. The original WCM checkpoint uses a different training recipe and supports a system-level, rather than component-isolated, comparison.

The 0722 OOD set (125 episodes) is the primary value-prediction evaluation; the 0814 5-cut set supports near-distribution analysis. Paired comparisons use identical episode/frame endpoints and 20,000 episode-level bootstrap resamples per seed. Mean squared error (MSE) is primary, while Pearson correlation, centered MSE, and mean bias diagnose ordering and calibration. The original WCM versus $H_{60}$ comparison uses 21,832 common OOD endpoints per seed. The $H_{60}$ versus $H_{120}$ comparison uses a separate manifest of 22,082 endpoints per seed. Absolute metrics are only compared within their respective manifests.

\subsection{Episode success/failure diagnostic}

The expanded-data checkpoint-validation split contains 18 episodes: 13 successes and five failures. We select one prediction per episode at frame index 2, the earliest common frame for the original WCM and \SpaceTime{} checkpoints. For \SpaceTime{}, a risk score $\sigma(r_t)\geq0.5$ predicts failure. For original WCM, the score is $-\hat V_t$; its threshold is selected on training episodes to maximize balanced accuracy and then frozen on validation episodes. We report correct episodes, failure recall, balanced accuracy, macro-F1, AUROC, and the underlying confusion counts. The same 18 episodes are reused across model seeds and were part of checkpoint selection, so the seed results are repeated model evaluations of one validation cohort.

Risk trajectories additionally sample one prediction per episode at fractions $0,0.25,0.5,0.75,1$ of the available window sequence. These fractions are computed from completed episode lengths for analysis; the fixed frame-2 comparison is the operational early-time readout. All five validation failures come from the 0703 failure collection, while 11 of 13 successes come from an 0814 success tail. Collection-related appearance is therefore a possible contributor to risk separation on this split.

\section{Results}

\subsection{Explicit visual history improves OOD value prediction}

On the 21,832-endpoint common OOD manifest, T8--$H_{60}$ reduced MSE relative to original WCM in each of three seeds (Table~\ref{tab:original}; Fig.~\ref{fig:original}). The paired MSE changes were $-0.11833$ (95\% CI $[-0.12618,-0.11060]$), $-0.08568$ ($[-0.09314,-0.07849]$), and $-0.09157$ ($[-0.09922,-0.08403]$) for seeds 3072, 42, and 1337. Pearson correlation increased for all three seeds. This establishes a repeatable system-level gain from the longer-history encoder under the evaluated OOD protocol.

\subsection{A longer span reduces error at fixed frame and query counts}

The controlled $H_{60}\rightarrow H_{120}$ comparison uses eight input frames and 64 output queries for both variants. On 22,082 paired OOD endpoints, extending the maximum offset to 120 reduced MSE in all three seeds (Table~\ref{tab:span}; Fig.~\ref{fig:span}). The paired changes ranged from $-0.00399$ to $-0.00688$, and every 95\% CI excluded zero. Pearson gains were clear for seeds 3072 and 1337; seed 42 had a positive point estimate whose interval crossed zero. The larger span therefore supports the paper's fixed-query history claim through consistent MSE improvements within the tested offset range.

\subsection{Failure scores on checkpoint validation episodes}

At the shared frame-2 readout, both \SpaceTime{} spans classified all 18 validation episodes correctly for each of three seeds. The original WCM value diagnostic classified 11, 13, and 13 episodes correctly for seeds 3072, 42, and 1337, respectively (Fig.~\ref{fig:classification}). Its failure recall was 0/5, 0/5, and 1/5, compared with 5/5 for each \SpaceTime{} checkpoint. The contrast describes the deployed systems and their respective score heads; it does not isolate the temporal encoder from the trained risk head.

\section{Discussion}

The controlled span experiment shows that a longer sampled visual history can be used through the same 64-query interface in this robot value-learning setting. Its OOD MSE gain repeats across three seeds even though the number of frames, query tokens, and trainable blocks is unchanged. The original-WCM comparison adds evidence for the complete history-encoding system, while its different training recipe prevents a component-only interpretation.

The success/failure diagnostic shows strong separation on the checkpoint-validation cohort, including at an early fixed frame. Two features of this experiment constrain its interpretation. First, the original WCM score comes from a calibrated value output and the \SpaceTime{} score comes from a supervised risk head. Second, outcome and collection source are associated in the 18-episode validation split. A source-matched, episode-disjoint mixed-outcome evaluation would distinguish task-outcome cues from collection appearance and test whether the observed separation transfers to new trajectories.

The fixed 64-query interface also has a computational cost: the T8 model has about 176.1 million parameters and an observed forward time of 12.9 ms per sample under the reported batch-four measurement, compared with 170.6 million parameters and 6.9 ms for original WCM. The current evidence covers one robot task family, two sampled spans, and an offline return target. It does not establish a monotone span scaling law or a guarantee that 64 queries retain all information in arbitrarily long histories.

\section{Conclusion}

\SpaceTime{} compresses eight sampled two-camera observations into 64 learned queries for WCM value prediction. On the evaluated OOD episodes, increasing the history span from 60 to 120 sampled offsets lowered paired MSE in all three seeds without changing the frame or query count. The result identifies a useful operating range for fixed-query history encoding and motivates source-matched tests of outcome prediction and additional span settings.

\appendix
\section{Input-mosaic control}

An input-level mosaic was evaluated as a reference. The four-frame version places observations in a $2\times2$ canvas; the eight-frame version places matched $H_{60}$ observations in a $2\times4$ canvas before a 224-pixel image processor. The eight-frame \SpaceTime{} system lowered OOD MSE relative to the eight-frame mosaic in seeds 3072 and 42 by $0.01800$ and $0.02455$, respectively (paired 95\% CIs $[-0.02065,-0.01538]$ and $[-0.02726,-0.02192]$). Pearson also increased by $0.02630$ and $0.02942$ with positive paired intervals. Mosaic frame count and canvas geometry are coupled in this comparison, so the result is a system reference rather than an isolated measurement of resolution loss.
